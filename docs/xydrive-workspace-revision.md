# Xydrive Beta

Enable **Xydrive Beta** under **Settings → Experimental**, then choose **Xydrive** from the main menu. The authenticated workspace opens at `#xydrive`.

- **My Drive** uses Saved Messages as the root. New folders create owned private Telegram broadcast channels. Mount channel attaches an existing eligible private channel. Folder nesting and display metadata live in the browser's account settings.
- Grid and list views show folders and files. Search includes the current folder and loaded results from its descendants. Favorites, Pinned, Recent, and Overview use the current session index. Scan all folders fetches bounded batches and offers another pass when older history remains.
- Preview uses Telegram Web's media viewer and audio player. The file picker and desktop drop target use native document uploads. The transfer center shows progress and offers cancellation where the native transfer supports it.
- Saved Messages and folders created by this beta support verified file moves and permanent deletion. Mounted channels support browsing, preview, download, and explicit upload. Older folder records without creation provenance are treated as mounted channels. Unmount removes the drive mapping and leaves the original channel and its files in Telegram.
- Rename in drive updates the display name in the current browser. Downloaded files keep their original Telegram filename.

The browser uses the account already signed in to TelegramX. TG-Drive's server-backed sharing links and durable background index and transfers require its separate backend.
