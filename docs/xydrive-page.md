# Xydrive full-page workspace

Dedicated authenticated view within the Telegram Web A shell, with native hash route (#xydrive), full viewport layout, desktop folder sidebar, mobile horizontal folder navigation and Back to chats. No modal or second session. Chat columns stay mounted but hidden. The native history hook handles Back; the existing media viewer remains outside the drive view. Direct initial hash opening requires the experimental setting and a synced authenticated account. Transfers retain the session queue. No server route rewrite is required.
